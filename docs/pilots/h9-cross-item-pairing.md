# H9 cross-item pairing check

The fixture bank includes 橋 with the same reading in `yomi` and `kakitori` formats, plus negative controls for a different reading, two recognition-only 川 items, and a diagnostic item.

Only the same-kanji/same-reading recognition-production pair is selected. A correct recognition response paired with an incorrect production response emits H9 evidence; equal outcomes and incomplete pairs emit none. This branch implements selection/evidence logic only and does not claim that the still-missing §7A persistence schema exists.
